Enable the first custom simulation

  1. County IT: name an approved cloud provider, region, technical administrator and spending limit. Use a protected HTTPS job API, persistent queue volume, one isolated model worker and private artifact storage. No credentials belong in this website or GitHub.
  2. GIS and model owner: obtain a complete permitted Fresno hydraulic project, not just an inundation PDF or image frames. Include terrain/bathymetry, geometry, bridges/culverts/gates, boundary and initial conditions, roughness, solver version and baseline outputs.
  3. Technical reviewer: reproduce the baseline and document numerical tolerances, coordinate/vertical references and supported parameter ranges. Select the first complete package meeting these checks; the county river priority does not substitute for a runnable model.
  4. Service administrator: install the pinned model adapter, prepare its checksummed package manifest and set the private template registry. A model-specific adapter must demonstrate input changes, output validation and process-tree cancellation. The generic worker does not guess HEC-RAS project edits.
  5. AGOL administrator: confirm the named-account EOC group and a separate technical-review group. The API verifies identity and membership server-side on each request. Register the approved service origin with the county app configuration and test two accounts.
  6. GIS: prepare an exposure subset for the modeled area using county footprints first, Overture context and NSI attributes. Review ambiguous matches, missing heights/foundation values and inventory dates. Reconcile terrain/model/building elevation references.
  7. Tabletop team: exercise submit, queue, cancellation, failure, result review and shift handoff. Only then enable the first template and configure the public app’s HTTPS service URL.

Available-model inventory

The project has twelve Fresno County hypothetical dam-failure visualizations. These visualizations principally interpolate published arrival and maximum-depth information; they are not complete local model packages. Recession and live forecast calibration are unavailable.

  • USACE Redbank/Fancher review plan: a documented hydraulic-modeling lead; request the actual package and permitted-use terms from the model owner.
  • San Joaquin/Friant and Kings/Pine Flat: request applicable county, DWR or USACE hydraulic models and responsible reviewers. No runnable package has been verified in this repository.
  • HEC-RAS examples can test adapters but do not establish Fresno coverage.

Understand the result

A completed run is a hypothetical calculation with frozen inputs. Technical review and briefing approval are separate. Building or road intersections identify records to inspect; they do not automatically establish interior flooding, road closure or safe access. Unknown depth, floor height or inventory coverage stays unknown.

Depth previews in the current library are 2D images draped on the map. Viewing them in 3D provides terrain context; it does not construct a modeled water surface. True water elevation and velocity animation require time-matched numeric outputs and reconciled vertical references.

Data preparation

Use GeoParquet for exposure analysis, vector tiles for map drawing, numeric COGs for terrain/depth/WSE, and chunked temporal data where justified. A smaller file is not automatically a faster map. Preserve source versions, geometry and numerical artifacts alongside display derivatives.
