Scope and refresh
Each selected layer queries intersecting IDs against the complete Fresno County polygon. Supply locations additionally require County = 'Fresno'; the county reference requires COUNTY_FIPS = '019'. An empty, failed or invalid ID response never becomes a statewide query. Inventory rows must reconcile exactly with verified county IDs before display. IDs are refreshed from the publisher rather than treated as permanent identifiers.
River segments, maintaining-agency polygons and regional polygons retain their full source geometry and can cross the county boundary. They are Fresno-intersecting references, not geometrically clipped county copies. The panel explicitly states this limitation.
Only supplies and offices start enabled in this optional group. Other layers are selected individually; minor-river geometry draws at 1:80,000 or closer. Source symbols are deserialized from the supplied web map using the existing pinned ArcGIS runtime; legends show the same symbols. The existing generic map-feature pane displays source attributes on selection.
Selected sources are rechecked every five minutes while the page is visible and the DWR group is displayed. A manual recheck is available. Queries run in the browser; no AGOL item, group, permission or hosted copy is created or edited. No scheduled collector or persistent browser inventory is introduced.

Interpretation
Inspection inventory is not confirmed current stock, an allocation, a reservation, or an approved pickup. Date-only inspection fields are displayed as UTC calendar dates to avoid a local-time day shift. Null quantities remain Unknown; explicit zeros remain zero. Refresh/query time is distinct from an inspection date. Confirm availability and release arrangements with DWR.
The layers do not establish present flow, levee reliability, forecast inundation, safe access or an operational resource commitment. Planning and notification rules are unchanged.
