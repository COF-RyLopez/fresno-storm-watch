NEARBY COUNTY PLACES
The side pane uses the complete selected WGS84 geometry and the existing SDK
geodetic-distance backend. An envelope prefilter only rejects distant candidates;
final inclusion uses full geometry, not its centroid or a bounding-box overlap.
Default: two horizontal miles, selectable 0.5/1/2/5 miles. These are vicinity
choices, not action thresholds, service territories, driving/access distances,
confirmed utility connections or outage exposure. Results are ordered by distance;
the nearest 12 per category are shown and full counts remain visible.

County facilities reuse authorized site sources and editor/source timestamps.
Pumps use the existing EOC-viewer read-only AGOL copy and authorizeDrainage guard;
no Enterprise fallback, source write, group membership or sharing change occurs.
Only existing pump records are included; proposed/unknown classes are excluded.
Readiness retains its PRIVATE EOC EXERCISE storage designation in this pane.
Confirm reports with FMFCD before operational use. It is resolved through the
existing version/conflict/validity checks, and
a fresh retrieval does not hide an old source verification. Source and retrieval
times remain separate. Known connected copies are reread every five minutes while
this pane is open and visible. This does not refresh the Enterprise-to-AGOL copy
or enable the pending county Notebook schedule.

Private features, readiness, contacts and queries live in memory only. Sign-out,
account change or failed access clears private candidates and map markers; late
private reads and superseded distance results cannot repopulate them. Model tests
exercise those races. Only public sources and clearly fictional exercise records
are in GitHub. No private record IDs or geometry are placed in form/share URLs.

The source checks and feature accounting accompany site/data/power-network.json.

Each query uses the complete Fresno County 06019 polygon, including its holes and
multipart geometry, through the ArcGIS server's intersects predicate. Selected
features are retained whole; some extend beyond county borders. The county polygon
is not a circuit service territory. ObjectID inventories are reconciled before and
after complete bounded batches; missing/repeated records, schema changes, unknown
CRS and partial responses fail the source. Identifiers remain strings.

GEOMETRY / PERFORMANCE
Services have differing original horizontal CRS. Publishers transform display
outputs to WGS84 (4326); response CRS is verified rather than guessed. Query
parameters generalize the DISPLAY geometry at 0.00005 degrees and six decimals.
This is a display derivative, not surveyed line position or electrical topology.
The full snapshot is bounded to 5,000 features per source / 1.5 million vertices.
It is loaded lazily in Power, not at every application launch.
PG&E LineDetail has nearly 180,000 county-intersecting records and is deliberately
not downloaded. Public feeder geometry supplies the distribution network overview.
More detailed line-section delivery would require a separate tiled design.

ASSOCIATION RULES
SCE outage Circuit_Number matches only the public circuit_no field. SCE PSPS
CIRCUIT_NAME matches only the original public circt_nam. Surrounding whitespace,
case and Unicode compatibility are normalized; punctuation, leading zeros and
voltage suffixes are not removed, padded or inferred. A single stable circuit_id
must resolve the value; contradictory group attributes or utility representations
suppress the match. Match semantics: agreement of published circuit identity,
not independent utility confirmation of current switching or every affected line.
The PG&E public outage/PSPS feeds used by this app do not supply a supported
circuit identifier. They remain explicitly unverified even beside a feeder.

Associated substations use the circuit publisher's name, restricted to an exact
unique station identifier and location in this reference. Missing/ambiguous station
coverage stays unknown; no nearest-line/site/station inference is performed.
Facilities retain the existing polygon-overlap rules and private access. This
release does not assert which circuit supplies a county building or pump.
Some circuit attributes or geometry are redacted; preserve the publisher's note.
No actual fault, electrical trace, energized/de-energized state or safe access is
computed from this reference. Outage/PSPS counts and hazard rules are unchanged.

REFRESH / FAILURES
The existing Pages workflow runs collect-power-network with a verified published
fallback. A successful reference check less than 24 hours old is reused; otherwise
each source is checked independently. Failed sources retain only their own dated
features and last successful time. No new paid service or credential is required.
The open Power workspace checks the published copy every five minutes. It does
not directly collect SCE planning services from each operator's browser.
Publisher edit dates/record dates, source retrieval and browser checks stay separate.
A failed reference, a check over 72 hours old, or an overdue outage source suppresses
verified highlighting. Dotted lines retain last-known reference geometry. Source
issues show each underlying check once and do not imply a power status change.
Closing/replacing evidence, switching workspace, lost source identity or a new
unverified revision clears the highlight. Refresh does not move the map.
