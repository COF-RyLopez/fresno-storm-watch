Onboarding accounting
23 source records = 11 active + 8 unknown + 4 inactive.
22 mapped points + 1 address-only record. The active City of San Joaquin record
has an address but no coordinates; no geocoding or substitute point is invented.
Default: 11 active records in the list, 10 mapped. Unknown and inactive records
require explicit filter selection. Source status is never interpreted as current
stock, staffing, hours, capacity, pickup authorization or safe road access.

Collection and failures
The existing Pages schedule attempts a public source refresh every 15 minutes;
the browser checks the prepared snapshot every five minutes while visible.
No browser call into the county network, credential, additional sign-in, AGOL
item, permission change or source edit is required. The existing app is unchanged.
Only allowlisted public location/status/date fields are retained; editor names,
arbitrary configuration, credentials and private inventory are excluded.
Read ID inventory, query bounded chunks, reconcile every ID, then recheck IDs.
Missing, duplicate, truncated, changed or malformed queries fail the collection.
Retain previous public references on failure with error and original lastSuccess;
never relabel a failed attempt as fresh data. Collection age >45 minutes is overdue.
Accounting is validated before display; no missing coordinate becomes 0/0.
FID is a source-local key, not a GlobalID or a guarantee across service replacement.

River / road context and map semantics
Reuse existing configured river watchpoints, within 25 km of each mapped site.
Reuse road geometry within 5 km of the site or the matched watchpoints, separately
labeled. Proximity is not a service area, flood boundary, network route or resource
assignment. Address-only records cannot be assigned a spatial match.
Retain active/unknown elapsed-date road records with verification warnings; an
elapsed end date never means reopened. Explicitly inactive records stay in Roads
history. No hazard thresholds, dispatch logic or incident-count changes are added.
Shovel/bag = source active; gray hollow diamond = unknown; gray x = inactive.
White selection ring = selected site; cyan rings = associated watchpoints.
Full road reference geometry retains the existing orange / dashed teal palette.
Background refresh updates graphics without re-enabling hidden map layers.
Live county records are disabled in the fictional exercise view.
