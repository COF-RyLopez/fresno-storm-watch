CONFIRMED DEFECTS / CORRECTIONS
UI-001 — FIXED IN CANDIDATE, LOCAL BROWSER RETEST PASSED
Selecting a care facility then using the NWS notification shortcut left the
Resident-care facilities pane beside a Weather Alerts map. Topic/mission changes
now close the active evidence pane through its normal cleanup/focus controller.
Same-topic selections are preserved. A controller regression test covers this.

UI-002 — FIXED IN CANDIDATE, LOCAL BROWSER RETEST PASSED
After Big Dry Creek was mapped, choosing Fancher Creek changed the selector but
left the Big Dry Creek map. This load-on-command behavior now explicitly says
which map remains displayed and that Inspect must be pressed for the new choice.
The active published scenario is also captioned above the map. Loading/error/no
map states have a visible status outside collapsed advanced-model setup.

NEXT CLEANUP BACKLOG (not fixed in this increment)
UI-003 — HIGH — Source health needs separate categories for actual failed checks,
missing publisher coverage, stale retained data, not-yet-loaded references and
private access not assessed. The observed single issue total mixed reference
layers with missing forecasts and check failures. Confirm expected coverage with
publishers; do not hide limitations or treat unsupported data as healthy.
UI-004 — MEDIUM — Explain count units/scope. Area reviews and the larger concern
list count different entities; neither is a count of independent incidents.
UI-005 — MEDIUM — Simplify Weather. Put the selected time/product/window near the
top; collapse tours and specialist controls. Check overlay/legend relationships
as radar, GOES, rainfall, NWS wind and HRRR change.
UI-006 — MEDIUM — Remove duplicate road-card actions (the record-name button and
Review record open the same detail). Preserve contradictory-date/history access;
old records cannot be silently interpreted as reopened roads.
UI-007 — MEDIUM — Improve briefing empty and unsaved states. A draft is tab-only;
add loss warnings, deliberate repeated-capture/version handling and clearer
sign-in/prerequisite actions. The signed-out private-save action correctly
reported that county sign-in was required, but this should be apparent sooner.
UI-008 — MEDIUM — General follow-up ownership/status needs an incident-linked
round trip into County Watch. Pump task ownership is already surfaced. Validate
other saved assignments with actual private exercise accounts before promising
assignment-state integration. No new activation controls are implied.
UI-009 — MEDIUM — Align private EOC / direct pump forms with the main app's task
language, navigation and empty/error states. An empty exercise Record history
screen had no explanatory empty-state text.
UI-010 — LOW — Grammar/plurals, small metadata text, focus return, touch targets,
legend density and nested scrolling need a systematic accessibility pass.
